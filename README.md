# Super Mango Mission Control
Development prototype only; no live business data on Hobby. Static frontend uses Supabase Auth and RLS. Create a confirmed test user via Supabase Authentication > Users, then a corresponding sm_members row with user_id and role admin/member using SQL editor. No self-service membership. Use Refresh to sync from database. Settings and deletion restricted to admin. Export JSON is a snapshot only. Dependencies are UI-validated; concurrent edits are last-write-wins. Do not publish service role keys. Production requires hosting that permits commercial use and full UAT.
